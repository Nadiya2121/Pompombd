নিচে আপনার প্রজেক্টের সমস্ত নতুন আপডেট (মাল্টি-পার্ট সিরিজ, অটো-ডিলিট টাইমার, ফরওয়ার্ড/সেভ প্রোটেকশন, সিনেমাটিক 16:9 ফ্রেম, অ্যাড রোটেশন ও ডিরেক্ট ইনবক্স ডেলিভারি) অন্তর্ভুক্ত করে একটি **১০০% নিখুঁত, প্রফেশনাল ও পূর্ণাঙ্গ `README.md`** ফাইল তৈরি করে দেওয়া হলো।

# 🎬 Pom Pom BD - Telegram Mini App & Advanced Video CMS Bot

## 🔍 প্রতিটি ফাইল ও ফোল্ডারের বিস্তারিত কার্যপ্রণালী (Detailed Technical Breakdown)

### ১. রুট ডিরেক্টরির ফাইলসমূহ:

* **`config.py`**:
  - অ্যাপের সমস্ত কনফিগারেশন সেন্ট্রালভাবে হ্যান্ডেল করে।
  - `APP_NAME` পরিবর্তন করে পুরো অ্যাপের নাম পরিবর্তন করা যায়।
  - `BOT_TOKEN`, `MONGO_URI`, `ADMIN_IDS`, `DB_CHANNEL_ID`, `IMGBB_API_KEY`, `WEBAPP_URL`, `ADMIN_PASSWORD` নিরাপদে পরিচালনা করে।
  - ওয়েলকাম পোস্টার ইমেজ এবং ওয়েলকাম টেক্সট নিয়ন্ত্রণ করে।

* **`main.py`**:
  - সিস্টেমের মূল হার্ট (Core Engine)।
  - আধুনিক **FastAPI Lifespan** আর্কিটেকচার ব্যবহার করে ওয়েব সার্ভার পরিচালনা করে।
  - টেলিগ্রাম বটকে ডেডিকেটেড নন-ব্লকিং থ্রেডে চালায় এবং টেলিগ্রামের কুখ্যাত **Error 409 Conflict** সমাধান করে সেশন ফ্রেশ রাখে।
  - `plugins/` ফোল্ডারের ভেতর থাকা সমস্ত প্লাগইন নিজে থেকেই স্ক্যান করে লোড করে।

* **`requirements.txt`**:
  - ক্লাউডে (Render / Koyeb) ডিপ্লয় করার জন্য প্রয়োজনীয় সমস্ত লাইব্রেরির তালিকা (`fastapi`, `uvicorn`, `pyTelegramBotAPI`, `motor`, `pymongo`, `requests` ইত্যাদি)।

* **`index.html`**:
  - টেলিগ্রাম মিনি অ্যাপের ক্লায়েন্ট ইন্টারফেস।
  - **YouTube 16:9 সিনেমাটিক ফ্রেম:** `object-fit: contain;` ব্যবহার করায় কোনো পোস্টার ছবি ১ মিলিমিটারও কেটে বাদ পড়বে না।
  - **মাল্টি-পার্ট সিলেক্টর:** থাম্বনেইলে ক্লিক করলে পার্ট বাছাইয়ের সুন্দর মডাল খোলে।
  - **হুবহু নিয়ন গ্লো কার্ড:** তালা আইকন, Free Ad Unlock এবং Coin Unlock বাটন সহ প্রিমিয়াম ডার্ক থিম।
  - **ব্যাক-বাটন অটো ডিটেকশন:** বিজ্ঞাপনে গিয়ে ৫/১০ সেকেন্ড পর ইউজার ফোনের Back প্রেস করলেই মিনি অ্যাপ নিজে থেকে কেটে যাবে এবং সাথে সাথে বটের চ্যাটে ভিডিও পৌঁছে যাবে।

* **`admin.html`**:
  - সম্পূর্ণ আলাদা ও সুরক্ষিত সুপার ওয়েব অ্যাডমিন ড্যাশবোর্ড (URL: `/admin`)।
  - **রিয়েলটাইম অ্যানালিটিক্স:** মোট অ্যাক্টিভ ইউজার, মোট ভিডিও, মোট অ্যাড ক্লিক ও লাইভ লিংক কাউন্টার।
  - **কনটেন্ট প্রোটেকশন সুইচ:** এক ক্লিকে ইউজারদের ভিডিও ফরওয়ার্ড ও গ্যালারিতে সেভ করা অন/অফ করার টগল বাটন।
  - **অটো-ডিলিট টাইমার কন্ট্রোল:** কত মিনিট পর ইউজারদের ইনবক্স থেকে ভিডিও মুছে যাবে তা সেট করার অপশন।
  - **অ্যাড গেট টাইমার কন্ট্রোল:** বিজ্ঞাপনে কত সেকেন্ড অপেক্ষা করতে হবে তা সেট করার অপশন।
  - **ডিরেক্ট লিংক ম্যানেজার:** আনলিমিটেড অ্যাড ডিরেক্ট লিংক যোগ করা, লাইভ ক্লিক সংখ্যা দেখা এবং ডিলিট করা।
  - **ভিডিও ও পার্টস ম্যানেজার:** টাইটেল ও 16:9 থাম্বনেইল এডিট, পুরো সিরিজ ডিলিট অথবা সিঙ্গেল নির্দিষ্ট পার্ট ডিলিট করার সুবিধা।

---

### ২. `plugins/` ডিরেক্টরির ফাইলসমূহ:

* **`plugins/__init__.py`**:
  - পাইথনকে ডিরেক্টরিটি একটি মডুলার প্যাকেজ হিসেবে নির্দেশ করে।

* **`plugins/uploader.py`**:
  - **প্রাইভেট DB চ্যানেল ব্যাকআপ:** অ্যাডমিন বটে ভিডিও পাঠালে সাথে সাথে প্রাইভেট ডাটাবেজ চ্যানেলে ফাইল ব্যাকআপ করে নেয়।
  - **ImgBB ক্লাউড CDN:** অ্যাডমিনের পাঠানো থাম্বনেইল ছবি স্বয়ংক্রিয়ভাবে কম্প্রেস করে ImgBB ক্লাউড CDN-এ আপলোড করে, যাতে অ্যাপে পলকের মধ্যে থাম্বনেইল লোড হয়।
  - **ইউনিক সিরিজ কোড (#101, #102):** প্রতিটি ভিডিওর জন্য স্বয়ংক্রিয় ইউনিক কোড তৈরি করে।
  - **স্মার্ট পার্টস সিস্টেম:** নতুন পার্ট যোগ করার সময় শুধু পার্ট নম্বর (`1` বা `2`) দিলেই তা `🎬 Video Part 1` বাটন হিসেবে রূপান্তর করে।
  - **ইনস্ট্যান্ট ডিরেক্ট ফাইল ডেলিভারি API (`/api/deliver-video`):** মিনি অ্যাপের কাজ শেষ হতেই সরাসরি ইউজারের চ্যাটে ফাইল পুশ করে।
  - **Self-Destructing Auto Delete:** নির্ধারিত মিনিট পার হওয়া মাত্রই ব্যাকগ্রাউন্ড থ্রেড চালিয়ে ইউজারের ইনবক্স থেকে স্বয়ংক্রিয়ভাবে ভিডিও মুছে দেয়।

* **`plugins/rotater.py`**:
  - **স্মার্ট লিংক রোটেশন:** একাধিক অ্যাড ডিরেক্ট লিংকের মধ্যে সবচেয়ে কম ক্লিক পড়া লিংকটি স্বয়ংক্রিয়ভাবে পরবর্তী ইউজারের জন্য সিলেক্ট করে।
  - মিনি অ্যাপে সিরিজ এবং তার ভেতরের সমস্ত পার্ট একসাথে লোড করার ব্যাকএন্ড API হ্যান্ডেল করে।

* **`plugins/manager.py`**:
  - অ্যাডমিন ড্যাশবোর্ডের সমস্ত সিকিউর এন্ডপয়েন্ট হ্যান্ডেল করে।
  - পাসওয়ার্ড ভেরিফিকেশন, স্ট্যাটাস ডেটা, ফরওয়ার্ড প্রোটেকশন টগল, অটো-ডিলিট মিনিট সেভ, ভিডিও এডিট ও ডিলিট API পরিচালনা করে।

## ⚙️ এনভায়রনমেন্ট ভ্যারিয়েবল তালিকা (Environment Variables)

Render বা Koyeb-এর **Environment** ট্যাবে নিচের নামগুলো দিয়ে আপনার আসল ভ্যালু সেট করুন:

| Variable Name | Description | Example / Default |
|---|---|---|
| `BOT_TOKEN` | BotFather থেকে পাওয়া আসল টেলিগ্রাম বট টোকেন | `7123456789:AAH...` |
| `MONGO_URI` | MongoDB Atlas ক্লাউড ডাটাবেজ কানেকশন স্ট্রিং | `mongodb+srv://user:pass@cluster.mongodb.net/...` |
| `ADMIN_IDS` | অ্যাডমিনের টেলিগ্রাম নিউমেরিক আইডি (কমা দিয়ে একাধিক) | `5370676246` |
| `DB_CHANNEL_ID` | প্রাইভেট ব্যাকআপ চ্যানেলের চ্যাট আইডি | `-1001234567890` |
| `IMGBB_API_KEY` | ImgBB ক্লাউড থেকে পাওয়া ফ্রি API Key | `32_digit_api_key` |
| `WEBAPP_URL` | Render/Koyeb ডিপ্লয়মেন্টের পর পাওয়া লাইভ ডোমেইন লিংক | `https://pompombd.onrender.com` |
| `ADMIN_PASSWORD` | ওয়েব অ্যাডমিন ড্যাশবোর্ডের লগইন পাসওয়ার্ড | `admin1234` |
| `APP_NAME` | মিনি অ্যাপ ও বটের নাম | `Pom Pom BD` |

   - **Environment:** `Python 3`

   - **Start Command:** `python main.py`
