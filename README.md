নিচে আপনার পুরো প্রজেক্টের জন্য একটি চমৎকার এবং সম্পূর্ণ **`README.md`** ফাইল তৈরি করে দেওয়া হলো। 

এটি আপনার গিটহাবের রুট ডিরেক্টরিতে রাখবেন। এতে প্রজেক্টের ফাইল স্ট্রাকচার, কোন ফাইলে কী লজিক কাজ করছে, এনভায়রনমেন্ট ভ্যারিয়েবল সেটআপ এবং Render/Koyeb-এ ডিপ্লয়মেন্টের বিস্তারিত গাইডলাইন দেওয়া আছে—যাতে পরবর্তীতে আপনি, অন্য কোনো ডেভেলপার বা যেকোনো এআই (AI) এক দেখাতেই পুরো সিস্টেমটি বুঝে ফেলতে পারে।

# 🎬 Pom Pom BD - Telegram Mini App & Video Monetization Bot

## 🔍 কোন ফোল্ডার/ফাইলে কী কাজ হয়? (Technical Breakdown)

### ১. রুট লেভেলের ফাইলসমূহ:

* **`config.py`**:
  - সমস্ত সিক্রেট কি, টোকেন এবং সেটিংস পরিচালনা করে।
  - `APP_NAME` পরিবর্তন করে যেকোনো মুহূর্তে সম্পূর্ণ সিস্টেমের ব্র্যান্ডিং পরিবর্তন করা যায়।
  - `ADMIN_IDS`, `MONGO_URI`, `BOT_TOKEN`, `WEBAPP_URL`, `ADMIN_PASSWORD` হ্যান্ডেল করে।

* **`main.py`**:
  - অ্যাপের মূল হার্ট (Engine)।
  - এটি **FastAPI** ওয়েব সার্ভার এবং **Python-Telegram-Bot** সার্ভিস ব্যাকগ্রাউন্ডে একসাথে চালায়।
  - **Dynamic Plugin Engine:** `plugins/` ফোল্ডারের ভেতর থাকা সমস্ত `.py` ফাইল স্বয়ংক্রিয়ভাবে রিড করে চালু করে (`setup` মেথডের মাধ্যমে)।

* **`requirements.txt`**:
  - Render বা Koyeb ক্লাউডে ডিপ্লয় করার জন্য প্রয়োজনীয় প্যাকেজগুলোর লিস্ট (FastAPI, Uvicorn, Motor, PyMongo, Python-Telegram-Bot ইত্যাদি)।

* **`index.html`**:
  - টেলিগ্রাম মিনি অ্যাপের ফ্রন্টএন্ড UI।
  - খাঁটি ইউটিউব স্টাইলের চ্যাপ্টা থাম্বনেইল ডিসপ্লে করার জন্য এতে `aspect-ratio: 16/9; object-fit: cover;` কোড যুক্ত করা আছে।
  - ভিডিও আনলক মডাল (Popup): Ad Unlock (কাউন্টডাউন টাইমার সহ) এবং Coins Unlock ইন্টারফেস।

* **`admin.html`**:
  - আপনার নিজস্ব ওয়েব অ্যাডমিন ড্যাশবোর্ড (URL: `/admin`)।
  - পাসওয়ার্ড দিয়ে সুরক্ষিত লগইন সিস্টেম।
  - আপলোড হওয়া সব ভিডিও দেখা, ইউটিউব থাম্বনেইল পরিবর্তন করা, টাইটেল/বাটন নাম ঠিক করা এবং ভিডিও ডিলিট করার ইন্টারফেস।
  - আনলিমিটেড অ্যাড ডিরেক্ট লিংক (Monetag, Adsterra ইত্যাদি) অ্যাড/রিমুভ করার এবং ক্লিক ট্র্যাকিং দেখার সুবিধা।

---

### ২. `plugins/` ডিরেক্টরি (মডুলার ফিচারসমূহ):

* **`plugins/__init__.py`**:
  - পাইথনকে নির্দেশ করে যে এটি একটি মডুলার প্যাকেজ ফোল্ডার।

* **`plugins/uploader.py`**:
  - টেলিগ্রাম বটে অ্যাডমিন কোনো ভিডিও ফরওয়ার্ড বা আপলোড করলে এই প্লাগইন তা ক্যাচ করে।
  - ৩ ধাপে কাজ করে:
    1. ভিডিও সনাক্ত করে ক্লাউড `file_id` স্টোরেজে নেয়।
    2. অ্যাডমিনের কাছ থেকে ভিডিওর টাইটেল চায়।
    3. অ্যাডমিনের কাছ থেকে বাটনের নাম বা পার্ট নম্বর (যেমন: Part 1, HD Watch) চেয়ে সবকিছু MongoDB-তে ইনসার্ট করে।
  - সাধারণ ইউজার বটে `/start` দিলে এই প্লাগইন সরাসরি মিনি অ্যাপ ওপেন করার ইনলাইন বাটন প্রদান করে।

* **`plugins/rotater.py`**:
  - অ্যাড ডিরেক্ট লিংক স্মার্ট রোটেশন ইঞ্জিন।
  - ডেটাবেজে সংরক্ষিত ডিরেক্ট লিংকগুলোর মধ্যে থেকে স্বয়ংক্রিয়ভাবে একেক ক্লিকে একেকটি লিঙ্ক প্রদান করে, যাতে বিজ্ঞাপন ব্লক না হয় এবং হাই-সিপিএম নিশ্চিত হয়।

* **`plugins/manager.py`**:
  - অ্যাডমিন প্যানেল এবং মিনি অ্যাপের জন্য প্রয়োজনীয় সমস্ত ব্যাকএন্ড API এন্ডপয়েন্ট হ্যান্ডেল করে (`/api/videos`, `/api/admin/edit-video`, `/api/admin/add-link`, ইত্যাদি)।

## ⚙️ এনভায়রনমেন্ট ভ্যারিয়েবল (Environment Variables)

Render বা Koyeb ড্যাশবোর্ডে নিচের ভ্যারিয়েবলগুলো সেট করতে হবে:

| Variable Name | Description | Example Value |
|---|---|---|
| `APP_NAME` | অ্যাপের নাম | `Pom Pom BD` |
| `PORT` | সার্ভার পোর্ট (ক্লাউডের জন্য) | `8080` |
| `BOT_TOKEN` | BotFather থেকে প্রাপ্ত টেলিগ্রাম বট টোকেন | `6987451234:AAH...` |
| `MONGO_URI` | MongoDB Atlas ক্লাউড কানেকশন স্ট্রিং | `mongodb+srv://user:pass@cluster.mongodb.net/...` |
| `ADMIN_IDS` | অ্যাডমিনের টেলিগ্রাম আইডি (কমা দিয়ে একাধিক) | `5370676246,12345678` |
| `WEBAPP_URL` | Render/Koyeb ডেপ্লয়মেন্টের পর প্রাপ্ত ডোমেইন | `https://pompom-bd.onrender.com` |
| `ADMIN_PASSWORD` | ওয়েব অ্যাডমিন ড্যাশবোর্ডের পাসওয়ার্ড | `admin1234` |

## 🚀 ক্লাউডে ডিপ্লয় করার নিয়ম (Render / Koyeb)

১. সম্পূর্ণ প্রজেক্টটি আপনার **GitHub** রিপোজিটরিতে পুশ করুন।  
২. **Render.com** অথবা **Koyeb.com** এ গিয়ে **New Web Service** সিলেক্ট করুন এবং আপনার GitHub রিপোজিটরিটি কানেক্ট করুন।  
৩. সেটিংস কনফিগার করুন:
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python main.py`
৪. **Environment Variables** ট্যাবে গিয়ে উপরের টেবিলের ভ্যালুগুলো যোগ করে **Deploy** দিন।

1. **ইউজারদের জন্য:**
   - বটে গিয়ে `/start` দিলেই মিনি অ্যাপের বাটন আসবে, অথবা টেলিগ্রাম চ্যাটের মেনু বাটন প্রেস করলে সরাসরি **16:9 ইউটিউব স্টাইলে** ভিডিও ফিড ওপেন হবে।
   - আনলক বাটনে ক্লিক করলে অ্যাড দেখে বা কয়েন খরচ করে আনলক করার পপআপ আসবে।

   - **বটের মাধ্যমে:** বটে ভিডিও ফরওয়ার্ড করলেই টাইটেল ও বাটনের নাম নিয়ে সরাসরি ডেটাবেজে পোস্ট হয়ে যাবে।
   - **ওয়েব প্যানেলের মাধ্যমে:** ব্রাউজারে `https://your-domain.com/admin` এ গিয়ে পাসওয়ার্ড দিয়ে লগইন করে থাম্বনেইল, টাইটেল, ডিরেক্ট লিংক ম্যানেজ ও এডিট করা যাবে।
